# درخشا Pro — جنگل دانش

هوش مصنوعی فارسی با طراحی امروزی و معماری جنگل دانش

**ساخته‌شده توسط گروک و احمدرضا ایزدی**

## لوگو
ترکیب درخت (تاج و ریشه) + نورون (هسته و دندریت) + پرتوهای درخشش

## بخش‌ها
- گفتگو (رابط شبیه هوش‌مصنوعی‌های روز)
- اسناد و دانش (افزودن مقاله، کتاب، سند با کلیدواژه)
- قابلیت‌ها (جنگل دانش، قشر زمانی، استدلال احتمالاتی، هرس پویا، فراشناخت، قیاس)
- درباره

## اجرا
فایل `index.html` را در مرورگر باز کنید یا روی GitHub Pages / Cloudflare Pages منتشر کنید.
