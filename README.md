## درباره پروژه

درخشا یک رابط گفتگوی فارسی است که روی معماری دانش ساخت‌یافته (درختی/هرمی) کار می‌کند.  
کاربر می‌تواند دانش جدید اضافه کند و سیستم هنگام پاسخ‌گویی ابتدا در دانش‌نامه جستجو می‌کند.

### سازندگان
| نقش | نام |
|-----|-----|
| معماری هوشمند و مدل | **گروک (Grok)** — ساخته‌شده توسط [xAI](https://x.ai) |
| ایده‌پردازی و بومی‌سازی | **احمدرضا ایزدی** |

> این پروژه به عنوان یک لایه رابط و دانش‌نامه روی ایده‌ها و قابلیت‌های گروک طراحی شده است.

## اتصال به گروک (xAI API) — اختیاری

درخشا در حالت پیش‌فرض با دانش محلی کار می‌کند.  
برای اتصال واقعی به مدل **Grok** از طریق API رسمی xAI:

### ۱. دریافت کلید API
1. برو به [console.x.ai](https://console.x.ai)
2. حساب بساز و اعتبار اضافه کن
3. از بخش **API Keys** یک کلید بساز

### ۲. مستندات رسمی
- [Quickstart](https://docs.x.ai/developers/quickstart)
- [Models](https://docs.x.ai/developers/models)
- Endpoint پایه: `https://api.x.ai/v1`

### ۳. نکته امنیتی مهم
**هرگز** کلید API را داخل فایل‌های عمومی GitHub (مثل `index.html`) قرار نده.  
برای اتصال واقعی یکی از این روش‌ها را استفاده کن:
- کلید را فقط در محیط محلی (LocalStorage یا `.env`) نگه دار
- یا یک Backend ساده (Serverless / Cloudflare Worker / Vercel) بساز که کلید را مخفی کند

## راه‌اندازی سریع با GitHub Pages

1. این مخزن را Fork یا فایل‌ها را آپلود کن
2. برو به **Settings → Pages**
3. Source را روی شاخه `main` بگذار
4. چند دقیقه صبر کن تا آدرس زیر فعال شود:

```
https://USERNAME.github.io/REPO-NAME
```
