# درخشا — جنگل دانش 🌲

هوش مصنوعی فارسی با معماری **جنگل دانش**

ساخته‌شده توسط **گروک (Grok)** و **احمدرضا ایزدی**

---

## معماری

| لایه | توضیح |
|------|--------|
| **جنگل دانش** | هر حوزه علمی یک درخت، هر مفهوم یک گره. مسیرها مثل نورون فعال می‌شوند |
| **قشر زمانی** | ثبت «کی» و روند تغییر مفاهیم در زمان — تحلیل روند و پیش‌بینی |
| **استدلال احتمالاتی** | چند مسیر موازی + Confidence Score |
| **هرس و پیوند پویا** | حذف مسیر کم‌استفاده؛ افزودن موقت از ورودی کاربر |
| **قشر فراشناخت** | تنظیم خودکار عمق تفکر (سطحی / متوسط / عمیق) |
| **استدلال قیاسی** | کشف الگوهای مشابه بین حوزه‌ها (مثلاً قلب ↔ پمپ) |

---

## فایل‌ها

| فایل | نقش |
|------|-----|
| `index.html` | رابط کاربری حرفه‌ای (خانه، گفتگو، نقشه جنگل، درباره) |
| `knowledge_forest.py` | موتور استدلال پایتون (قابل اجرا و توسعه در GitHub) |
| `forest_state.json` | نمونه وضعیت ذخیره‌شده جنگل |

---

## اجرای موتور پایتون

```bash
python knowledge_forest.py
```

موتور شامل:
- فعال‌سازی نورونی گره‌ها
- مسیرهای احتمالاتی
- قیاس بین‌حوزه‌ای
- هرس پویا
- پیوند از ورودی کاربر

---

## لوگو

ترکیب:
- **درخت** (تاج و ریشه) → جنگل دانش
- **نورون** (هسته درخشان + دندریت) → فعال‌سازی مفهومی
- **پرتو نور** → درخشش و روشنایی

---

## سازندگان

- **گروک (Grok)** — معماری هوشمند
- **احمدرضا ایزدی** — ایده‌پردازی و بومی‌سازی
