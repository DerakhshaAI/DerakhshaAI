# هوش مصنوعی درخشا ✨

مجموعه کامل پرامپت‌ها و جملات گپ زدن برای **هوش مصنوعی درخشا**

ساخته‌شده توسط **گروک** و **احمدرضا ایزدی**

---

## فایل اصلی

- [`index.html`](index.html) — صفحه کامل و تعاملی پرامپت‌ها (آماده برای آپلود در GitHub Pages)

## قابلیت‌های صفحه

- بیش از **۲۵۰ پرامپت** دسته‌بندی‌شده
- جستجوی زنده
- دسته‌بندی‌ها: همه / معرفی سیستم / درباره سازندگان / روزمره / آموزشی / خلاقانه / فنی / علاقه‌مندی‌ها / نمونه پاسخ‌ها
- سیستم **علاقه‌مندی‌ها** (ذخیره در مرورگر)
- دکمه **پرامپت تصادفی**
- کپی تکی و کپی همه
- حالت روشن / تاریک
- طراحی مدرن، ریسپانسیو و راست‌چین
- کاملاً بدون نیاز به سرور (Static)

## نحوه استفاده در GitHub

1. این مخزن را Fork یا Clone کنید
2. فایل `index.html` را به عنوان صفحه اصلی نگه دارید
3. در تنظیمات مخزن، GitHub Pages را فعال کنید (Source: main branch)
4. صفحه در آدرس `https://USERNAME.github.io/REPO-NAME` در دسترس خواهد بود
