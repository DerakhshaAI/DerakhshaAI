# هوش مصنوعی درخشا ✨

دستیار هوشمند فارسی‌زبان با صفحه گفتگوی تعاملی و مجموعه پرامپت‌های پیشنهادی.

**ساخته‌شده توسط گروک و احمدرضا ایزدی**

---

## فایل اصلی

- [`index.html`](index.html) — اپلیکیشن کامل (آماده GitHub Pages)

## قابلیت‌های جدید

### صفحه گفتگو (Chat)
- رابط کاربری مدرن شبیه چت‌بات‌های حرفه‌ای
- پاسخ‌های هوشمند شبیه‌سازی‌شده بر اساس کلمات کلیدی
- نشانگر تایپ (Typing indicator)
- پیشنهادهای سریع (Chips)
- پاک‌کردن گفتگو

### لوگو حرفه‌ای
- طراحی SVG اختصاصی بر اساس مفهوم «درخشش»
- گرادیان بنفش-فیروزه‌ای + افکت درخشش
- کاملاً مقیاس‌پذیر و بدون نیاز به فایل تصویری

### افزودن فایل (غیرفعال)
- دکمه افزودن فایل، تصویر و ورودی صوتی وجود دارد
- فعلاً غیرفعال است و برچسب «به‌زودی» دارد
- آماده فعال‌سازی در نسخه‌های بعدی

### سایر ویژگی‌ها
- بیش از ۱۰۰ پرامپت دسته‌بندی‌شده
- سیستم علاقه‌مندی‌ها (LocalStorage)
- جستجوی زنده
- پرامپت تصادفی
- ارسال مستقیم پرامپت به صفحه گفتگو
- حالت روشن / تاریک
- ناوبری موبایل
- کاملاً Static و بدون نیاز به سرور

## نحوه استفاده در GitHub

1. فایل‌ها را در مخزن آپلود کنید
2. Settings → Pages → Source: `main` branch
3. صفحه در آدرس `https://USERNAME.github.io/REPO-NAME` در دسترس خواهد بود
