# درخشا — سامانه هوش مصنوعی درخت دانش

طراحی و توسعه مفهومی: **گروک** و **احمدرضا ایزدی**

## محیط سایت (نسخه ۱)

- منوی بالا
- حس جدی و علمی
- پالت رنگی: فیروزه‌ای، آبی، بنفش
- صفحات: گفتگو · دانش من · درخت دانش · قابلیت‌ها · درباره

## اجرا

فایل `index.html` را در مرورگر باز کنید یا روی GitHub Pages / Cloudflare Pages منتشر کنید.

## قابلیت‌های متصل به UI

- گفتگو با منبع و سطح اطمینان
- افزودن سند/مقاله/کتاب با طبقه‌بندی خودکار
- نمایش شاخه‌های درخت دانش
- ذخیره دانش در LocalStorage مرورگر
