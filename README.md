# Derakhsha AI Prototype 0.1

## اجرا در ویندوز
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
سپس `http://127.0.0.1:8000` را باز کنید.

این نسخه یک prototype است: رابط مدرن RTL + API + تحلیل اولیه فارسی + درخت دانش + جستجوی کل↔جز + امتیازدهی + جمله‌ساز.
