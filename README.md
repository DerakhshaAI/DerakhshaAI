# درخشا — اپ تحت‌وب (PWA)

سامانه هوش مصنوعی فارسی با معماری **درخت دانش**  
طراحی مفهومی: **گروک** و **احمدرضا ایزدی**

## ویژگی‌ها

- رابط گفتگو (RTL، تم تاریک/روشن)
- موتور درخت دانش سمت‌کلاینت (بدون نیاز به سرور برای دمو)
- ورود آزمایشی با شماره + کد `123456`
- تاریخچه گفتگو (localStorage)
- قابل نصب روی موبایل به‌صورت PWA
- آماده اتصال به API واقعی

## اجرا

هر سرور استاتیک کافی است:

```bash
# مثلاً با Python
python -m http.server 8080

# یا با npx
npx serve .
```

سپس در مرورگر: `http://localhost:8080`

## اتصال به API واقعی

قبل از لود اسکریپت‌ها در `index.html` (یا در کنسول):

```js
window.DERAKHSHA_API = "https://your-backend.example.com";
```

endpoint مورد انتظار:

```
POST /api/chat
Body: { "message": "...", "session_id": "..." }
Response: {
  "answer": "...",
  "source": "هسته درخت دانش",
  "confidence": 90,
  "branch": "معماری",
  "route": "tree"
}
```

اگر `DERAKHSHA_API` تنظیم نشود، موتور محلی (`engine.js`) پاسخ می‌دهد.

## ساختار فایل‌ها

| فایل | نقش |
|------|------|
| `index.html` | اسکلت صفحه |
| `styles.css` | استایل |
| `app.js` | منطق UI، سشن، ورود |
| `engine.js` | درخت دانش و پردازش پیام |
| `manifest.json` | PWA |
| `sw.js` | Service Worker (کش آفلاین) |

## آیکون‌ها

برای نصب کامل PWA دو فایل PNG بسازید:

- `icon-192.png` (۱۹۲×۱۹۲)
- `icon-512.png` (۵۱۲×۵۱۲)

می‌توانید از لوگوی SVG موجود در صفحه خروجی بگیرید.
