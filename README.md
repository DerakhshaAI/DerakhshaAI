# هوش مصنوعی درخشا ✨

دستیار هوشمند فارسی با معماری دانش قابل‌گسترش

**ساخته‌شده توسط گروک و احمدرضا ایزدی**

---

## فایل اصلی
- `index.html` — اپلیکیشن کامل (Static، مناسب GitHub Pages)

## ویژگی‌ها

### لوگوی اختصاصی
ترکیب **درخت** (رشد و ریشه) + **نورون** (هوش مصنوعی) + **پرتوهای نور** (درخشش)

### صفحه گفتگو
- رابط ساده و حرفه‌ای
- پاسخ‌گویی بر اساس دانش‌نامه
- پیشنهادهای سریع
- افزودن فایل/تصویر/صوت (غیرفعال — به‌زودی)

### دانش‌نامه (جایگزین پرامپت‌ها)
- افزودن جفت سوال و پاسخ جدید
- ذخیره در مرورگر (LocalStorage)
- جستجوی هوشمند هنگام گفتگو
- خروجی JSON
- ۱۵ سوال‌وجواب پیش‌فرض آماده

### معماری دانش درخشا
اطلاعات به صورت ساخت‌یافته (سوال → پاسخ) ذخیره می‌شوند و هنگام گفتگو سیستم ابتدا در دانش‌نامه جستجو می‌کند.

## سازندگان

- احمدرضا ایزدی
